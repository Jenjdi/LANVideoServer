# 运行与安全审查

审查对象为 V1.0 的 C++ 服务、浏览器界面、构建部署脚本和发行材料。检查覆盖输入处理、认证和资源隔离、路径与文件身份、BT 分片读取、代理握手、连接期限、停机和敏感信息分发。

## 已确认并修复的问题

|问题|影响及触发条件|修复与验证|
|---|---|---|
|慢速请求持续占用工作线程|未登录客户端按间隔发送不完整请求头，可绕过逐次读取超时；8 个连接占满线程后健康请求超时|请求头总期限 10 秒、总大小 16 KiB，普通请求体 10 秒、已通过预检的上传 120 秒；期限耗尽后关闭连接。8 连接慢速发送及停机测试通过|
|续传清理缺少文件身份检查|共享目录或暂存文件被本地替换后，取消或到期清理可能删除同名无关文件|核对目录设备/inode、暂存文件设备/inode、类型和链接数；身份不匹配拒绝删除。到期与主动取消测试均保留替换文件|
|本地模式缺少 Origin 检查|浏览器跨站提交可建立登录或分享会话|本地模式比对 HTTP Host 与 Origin，HTTPS 模式使用配置的公开 Origin；拒绝重复 Origin。跨站请求返回 403，同源操作正常|
|JSON 重复键和解析深度未约束|重复字段被后值覆盖，造成输入解释不一致|统一解析拒绝重复键、超过 32 层的嵌套和超限内容；普通 JSON 上限 4 KiB，续传清单上限 300 KiB|
|SOCKS5 测试接受未协商的认证方式|配置账号密码时，测试仍可接受代理返回的免认证方式并报告成功|要求代理选择客户端实际提供的方式，同时验证 CONNECT 保留字节。旧包可复现返回 200，修复后返回 502|
|IPv4 字符串含 NUL 后缀|地址解析只读取 NUL 前内容，校验与保存值不一致|拒绝含 NUL 的代理地址及入口客户端地址；回归返回 400|
|私有目录和数据库链接检查不足|配置目录为符号链接时可能先修改目标权限；数据库链接可把写入指向外部文件|逐级无链接目录创建并通过文件描述符设置权限；数据库及 WAL/SHM/journal 要求私有、当前账号所有、普通文件和单链接，SQLite 使用 NOFOLLOW；代理密钥拒绝硬链接|
|BT 首帧片调度不稳定|限速下载时窗口内同优先级分片可能延后首片，实测约 69% 下载后仍连续 503、首帧超时|焦点阶段给当前播放片设置 libtorrent 500 ms 请求期限；后台阶段、焦点切换及失效时撤销期限，保留基准调度|
|文件时间戳边界溢出|极端时间戳的纳秒加法可能发生有符号溢出|乘法前按纳秒余量检查上界；不支持的时间戳返回错误|
|远程诊断和停机等待期限不足|HTTPS 端点持续慢速响应可能延长诊断；不完整 HTTP 请求可能延迟停止|HTTPS 探测增加 6 秒网络停止计时器并复核操作身份；HTTP 等待检查监听状态，SIGTERM 中断未完成请求|

旧包的失败测试是问题复现记录，不计入修复后的通过结果。新增回归文件为 `tests/security_regression.py`。

## 验证范围

Release 回归包括认证、媒体、上传续传、BT、分片播放、分享、HTTPS、监控、安装迁移和安全回归。浏览器测试使用 Chromium，下载测试使用独立 libtorrent Seeder、HTTP Tracker 和认证代理。文件、Range 与 BT 分片比较实际字节；播放测试由原生播放器解码并拖动。

最终命令和结果记录于 `review-test-results.json`。ASan/UBSan 检查仅覆盖记录中列出的 runner；第三方动态库未重新插桩。安装归档另行检查清单、资源迁移、健康、匿名权限、首次初始化状态和停止行为。

## 部署边界

本次检查及本机测试不能证明不存在其他漏洞，也不代表某项安全等级。公网跨 NAT、公共 BT swarm、证书自动续期和生产负载没有本次实测。默认 HTTP 不保护网络中的密码传输；公网部署必须使用 HTTPS，私有目录由独立服务账号控制。

BT 用户能发起 Tracker/Peer 网络连接；不应向不受信任的匿名用户开放下载账号。管理员选择的目录和代理目标属于管理权限。HTTPS 探测计时器不替代操作系统 DNS 解析器的超时管理。分享撤销限制后续读取，不能收回已发送的数据。

当前任务数和种子大小上限不等同于磁盘总配额，移除 BT 任务会保留文件。部署时应给下载数据设置独立卷或系统配额，并监测可用空间；不应将本版本开放给任意注册的下载用户。
