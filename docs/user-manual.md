# 用户手册：轻量级视频共享与传输软件 V1.0

## 首次运行

按 [部署运维手册](deployment.md) 构建或安装。在服务器终端运行 `./build/lanvideo --init-admin`（安装包使用 `bin/lanvideo --init-admin`），输入自己的用户名和密码。密码至少12字节，终端隐藏输入并确认；同一数据库只允许初始化一次。没有公开默认密码，也没有远程创建首个管理员的接口。服务运行时也可初始化同一数据库，须使用相同LANVIDEO_DATA。

启动后从与服务网络可达的浏览器访问根页面。默认回环HTTP只在本机可达；局域网需显式设置合适bind，公网需要已验证的HTTPS入口。云onboarding界面不提供回环地址网页预览。界面明确显示HTTP/HTTPS连接类型。用户名与密码登录，退出清除当前会话；修改密码后重新登录。管理员禁用、修改角色或重置密码会使已有会话失效。

## 管理员：建立视频库

1. 「管理」设置服务器上的绝对共享目录。目录及文件不能使用符号链接；不允许共享整个文件系统或托管BT目录。服务用户需具备相应读写权限。
2. 点击「扫描视频」。显示真实名称、大小、扩展格式；FFprobe可用时读取视频流与时长，不可用时显示时长未知。扫描最多500个视频/10000目录项/20秒，超限需缩小目录。
3. 可从管理页直接上传本地视频。默认最大512MiB，可配置1..4096MiB；重名拒绝覆盖。整文件上传进度来自XHR真实字节事件，成功发布才显示上传成功。
4. 为较大文件勾选「启用分块断点续传」。客户端逐块计算SHA256，服务端核对每个1MiB块并持久化确认偏移。暂停/断网/刷新/服务重启后，选择同名、同大小且内容一致的文件继续。断点保留24小时；未完成文件不出现在视频库。放弃时使用上传编号删除断点，成功发布的文件不会随编号删除。
5. 创建普通用户。在视频卡片点击「授权」，勾选启用的普通账号，保存后该用户可以读取此视频。管理员访问全部目录资源；普通用户不能修改共享目录、扫描、上传或签发分享。

更换共享目录会清除旧目录索引、账号授权、播放记录及相关分享，需重新扫描和授权。外部修改/替换文件会使原接口返回409，须重扫；变更文件会得到新编号，旧授权不会自动转移。扫描不会删除实际文件。

## 普通用户：播放与自己的记录

在「视频库」按文件名搜索或筛选格式，点击「播放」。浏览器原生video通过HTTP Range读取资源，拖动进度条定位；服务端在读取时重新校验登录、权限、路径和文件身份。自己的播放位置每5秒及暂停/定位时保存，刷新后再次打开视频继续；不会读取另一账号的记录。

实测编码为H.264 faststart MP4，浏览器实测为当前环境的Chromium。列出扩展名不等于浏览器能解码所有容器/编码组合；不支持的编码需在软件外转换。播放失败时界面提示连接、授权、文件变更或解码问题。本软件不提供转码、HLS或MSE。

## BT 下载与边下载边播放

「BT下载」导入自己有权下载的v1 `.torrent`；新任务默认暂停，点击「恢复」才联网。状态来自实际libtorrent会话：校验完成率、已验证字节、下载速度、连接中的Peer/Seed及错误。Peer数是当前连接数，不是全网用户数。普通用户只访问自己的任务，管理员可管理全部任务。

可暂停、恢复、重新校验、移除。暂停是异步命令，应查看实际状态；重新校验读取磁盘分片，损坏片回到未完成并可重新下载。移除任务保留磁盘文件，需要管理员手工管理。完成后任务可能继续向Peer上传，暂停可停止。任务及resume信息持久化，重启会重新校验现有文件。

点击「视频文件」查看种子中的视频，点击播放。仅通过完整分片哈希的数据会输出，再次SHA1核对后形成内存快照；预分配的零填充或未校验字节不会当作视频输出。缺少区域最多等2秒，返回503/Retry-After；播放器自动重试，30次后需手动重试。暂停任务、没有可用Peer、限速或容器布局不适合流式读取时可能长时间等待，界面不会用假缓冲进度掩盖。焦点调度会周期恢复普通优先级；不保证任意网络下无卡顿。

托管BT目录不能经普通媒体接口扫描/分享。若需要分享完整下载的文件，可确认下载与校验完成后，将完整文件复制至普通共享目录，扫描并创建分享；当前不提供BT未完成分片的匿名分享。

## 管理员：代理、远程入口与分享

BT出站配置支持HTTP/SOCKS5和可选认证。修改代理前暂停全部任务并等待连接关闭；重新输入需要保存的凭据，界面不回显。代理与连接测试目标暂限IPv4字面地址。连接测试实际完成代理握手和TCP连接并显示实测时间，但不等于完整BT下载成功。HTTP/SOCKS5到代理的认证不自行加密，需可信出口或受保护网络。代理失败不自动改为直连。

远程入口是另一项独立配置：由同机Nginx提供HTTPS，后端继续回环HTTP，入口密钥和转发信息由服务端验证。管理页可测试已配置入口，区分证书、连接、错误服务等故障；仅证明本机到入口连通，未证明公网/跨NAT。配置失败不会自动跳至HTTP；部署说明见 [remote.md](remote.md)。

在视频卡片点击「分享」，选择有效期（30秒至7天）并创建链接。链接令牌只显示一次，列表只保留元数据。接收者无需主账号，只能读取这一个完整视频。其播放会话最长1小时，超时后重新打开原链接；管理员可撤销，签发者账号/角色/密码变化也永久撤销。新请求立即拒绝，进行中的输出在下一块检查时中断；浏览器已缓冲或收件人已保存的字节无法追回。分享是读取授权，不能阻止接收者保存视频。

## 运行状态与审计

管理页「运行状态与操作审计」显示实际数据库快照、账号/媒体/任务/分享计数、当前会话数、运行时间和数据所在文件系统的可用空间。点击刷新获取新快照，不使用计时器猜测状态。任务暂停数是请求暂停状态，真正的传输状态和速度请到BT页查看；数据卷可用空间不是所有共享目录磁盘空间或用户配额。

审计按最近编号展示初始化、登录、账号/密码、媒体上传/授权、BT任务与代理配置、分享签发/撤销等已记录操作，可以继续读取更早记录。只允许管理员访问，既不显示密码/会话令牌/代理凭据，也不提供删除审计接口。审计是数据库记录，不是实时stdout日志；info/error日志级别不会关闭审计。详细API、日志与存储维护见 [monitoring.md](monitoring.md)。

## 常见问题

|现象|操作|
|---|---|
|401|登录已失效；重新登录或重新打开有效分享链接|
|403|当前账号/资源授权不足，或请求未经过正确HTTPS入口；不要以隐藏按钮代替权限检查|
|404|文件/任务不存在、分享失效或资源已重扫移除；刷新并联系管理员|
|409|文件或根目录变化、重名、任务状态冲突；依据提示重扫、暂停或选新文件名|
|413/422|请求/种子/上传超限或分块校验失败；缩小输入、选择正确原始文件|
|416|Range不可满足；正常浏览器会按实际文件长度请求，不手工构造越界范围|
|429|登录/密码校验/分享会话或诊断额度忙；等待提示期限再试|
|503 + Retry-After|BT分片尚未完整可用，等待真实下载或检查Peer/暂停状态|
|代理超时/502|检查代理地址、认证和真实目标连接；不会显示模拟连接成功|
|HTTPS错误|核对证书链、域名、入口与后端；不关闭校验，不降级公网HTTP|

完整功能状态与尚未验证能力见 [feature-status.md](feature-status.md)。
