# 轻量级视频共享与传输软件 V1.0
# 软件说明书

## 一、软件概述

轻量级视频共享与传输软件是一套面向个人和小型团队的视频资源管理系统。软件采用浏览器与服务端分离的结构，服务端以 C++20 开发，负责账号认证、资源授权、文件传输和下载任务管理；浏览器提供视频库、播放、上传和管理界面。

软件将本地视频共享、断点续传上传、BT 下载及分片播放集中到同一操作界面。管理员统一维护用户和资源，普通用户在授权范围内浏览视频、保存播放位置，并管理自己的下载任务。

## 三、用户与权限管理

### 3.1 管理员初始化

软件首次使用时，由服务器操作者执行管理员初始化命令。程序通过终端读取账号和密码，密码输入不回显。初始化结果保存到数据库，同一数据库只允许执行一次。

### 3.2 登录与会话

用户输入账号和密码登录。服务端使用带随机盐的 Argon2id 密码哈希验证身份，并建立有期限的会话。用户可以退出登录和修改密码。密码修改、账号禁用、密码重置及角色变化会使原有会话失效。

### 3.3 账号维护

管理员可创建用户、分配管理员或普通用户角色、禁用与启用账号、重置密码及删除用户。软件校验最后一个可用管理员，避免管理账号被全部停用或删除。

### 3.4 资源权限

管理员为视频设置可访问用户。普通用户的视频库仅显示已授权资源，播放接口再次检查账号、授权和文件路径。普通用户的播放记录和 BT 任务按账号隔离。

## 四、视频资源管理与播放

### 4.1 共享目录与扫描

管理员配置共享根目录并执行扫描。系统识别支持的视频文件，读取文件名、大小和格式，写入媒体索引。安装 FFprobe 后，扫描同时读取视频时长。视频库支持按名称搜索及按格式筛选。

### 4.2 在线播放

浏览器使用原生视频播放器。服务端支持完整文件响应和单段 HTTP Range 响应，处理指定起止位置、开放结束位置及文件尾部范围。播放器可通过范围请求读取目标位置的数据，支持拖动播放。

对于越界范围、缺失文件及索引后发生变化的文件，系统返回相应错误，提示用户刷新索引或重试。

### 4.3 播放记录

播放位置与更新时间按用户保存到数据库。重新打开视频时，界面读取该账号保存的位置并继续播放。视频记录与访问授权共同校验。

## 五、本地文件上传

### 5.1 整文件上传

管理员从浏览器选择本地视频并上传到共享目录。界面根据实际发送字节显示进度。服务端检查文件名、大小和视频容器，上传完成后登记媒体信息。目标文件重名时拒绝覆盖。

### 5.2 分块断点续传

续传模式将文件划分为 1 MiB 分块，并计算各块 SHA256。服务端创建上传会话，校验每块数据，落盘并同步后保存确认偏移。用户暂停、断网、刷新页面或服务重启后，重新选择相同文件即可从确认位置继续。

上传会话保留 24 小时。重复提交已确认分块不会重复增加进度。文件全部收到后，服务端复核分块和完整文件，检查视频格式，并以禁止覆盖的方式发布。管理员可主动放弃未完成上传。

## 六、BT 下载与代理

### 6.1 种子导入与任务控制

用户导入 v1 `.torrent` 文件。服务端校验种子元数据、文件路径和资源数量，在受控目录内创建任务。任务初始暂停，用户可恢复、暂停、重新校验或移除任务。

BT 协议处理由 libtorrent-rasterbar 提供，包括 Tracker 通信、TCP Peer 连接、分片下载和哈希校验。任务页面显示库提供的完成率、下载速度、连接数和错误状态。服务停止时保存恢复数据，重启后重新检查下载文件。

### 6.2 下载目录

管理员设置下载根目录。每个任务使用独立目录保存文件，系统约束种子中的相对路径，并拒绝不安全路径和符号链接。移除任务保留已下载文件，供管理员处理。

### 6.3 出站代理

管理员可配置 HTTP 或 SOCKS5 代理、地址、端口、认证信息和超时时间。代理作用于 BT 出站连接。凭据通过本地密钥加密保存，界面只显示凭据是否已配置。

连接测试执行代理握手及目标 TCP 连接，区分认证失败、连接拒绝和超时。SOCKS5 测试校验代理选择的认证方式与客户端协商结果。

## 七、边下载边播放

系统根据视频文件在种子中的字节偏移，将播放范围映射到 BT 分片。读取接口只提供完整下载且校验通过的分片；分片读取后再次核对 SHA1，并通过不可变数据快照发送给播放器。

播放器的位置用于提高附近分片的下载优先级，并为当前播放片设置下载期限。调度器周期性撤销该期限并恢复普通优先级，兼顾后续播放和其他分片下载。请求区域尚未就绪时，接口返回等待与重试结果，播放器按提示继续请求。BT 视频播放位置按账号、任务及文件保存。

## 八、HTTPS 访问与视频分享

### 8.1 反向代理适配

软件提供本地访问及 HTTPS 反向代理适配接口。反向代理模式下，C++ 服务监听回环地址，Nginx 接收 HTTPS 请求并转发。服务端核验私有入口标识、协议、主机和客户端地址。

管理员可执行入口诊断。诊断验证 TLS 证书、主机名以及目标服务身份，并展示连接结果。入口失败时保持访问限制，由管理员按部署配置恢复服务。

### 8.2 限时分享

管理员为一个完整视频创建分享链接，指定有效期并可随时撤销。链接令牌通过专用接口换取仅适用于分享页面的会话。接收者获得该视频的读取权限，可在浏览器播放和拖动。

分享读取过程中持续检查有效期、撤销状态、签发者权限及文件身份。签发者密码或角色发生变化、账号被禁用或删除时，其分享授权失效。

## 九、运行状态与操作审计

管理员状态页展示服务运行时长、用户及媒体数量、上传与 BT 任务统计、共享和下载目录的磁盘空间。数据来自当前数据库及文件系统查询。

关键操作写入审计表，包含时间、操作者、事件及必要的对象信息。管理员可分页查看审计记录。应用日志采用 JSON 格式，支持信息和错误级别，不记录密码、会话令牌或代理凭据。

## 十、模块与数据组织

|模块|职责|
|---|---|
|core、http_server|配置加载、错误响应、数据库访问、事务、日志和 HTTP 请求期限|
|auth|账号、密码、会话、角色与权限校验|
|files、media|文件路径检查、扫描、元数据、授权和 Range 传输|
|uploads|分块校验、持久偏移、续传与文件发布|
|bt、bt_stream|BT 任务、恢复数据、分片读取和播放调度|
|proxy|HTTP、SOCKS5 握手与连接测试|
|remote、shares|HTTPS 入口适配、诊断、分享授权与读取|
|monitor、web|运行状态、审计查询及浏览器操作界面|

数据库保存用户、会话、视频索引、资源授权、播放记录、上传会话、下载任务、BT 播放位置、分享链接、分享会话、配置及审计记录。视频、下载数据和种子元数据分别存放在受控目录中。

## 十一、安装与操作流程

1. 安装开发依赖，使用 CMake 构建服务。
2. 设置数据目录，在服务器终端初始化管理员。
3. 启动服务，通过浏览器登录管理员账号。
4. 创建普通用户，配置共享目录，扫描或上传视频。
5. 设置视频访问用户，使用普通账号浏览和播放。
6. 导入种子并恢复下载，选择任务中的视频进行分片播放。
7. 按部署需要配置 BT 出站代理、HTTPS 入口及限时分享。
8. 在管理页查看运行状态和操作记录。

程序支持 SIGINT、SIGTERM 停止，停止时关闭 HTTP 服务并保存 BT 恢复信息。发行包包含可执行文件、网页资源、说明和许可通知；运行数据、账号数据库及私有密钥由部署目录独立保存。
